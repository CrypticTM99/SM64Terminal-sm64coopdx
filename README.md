# SM64Terminal-sm64coopdx
A minigame + 'bmod' inspired mod that allows you to open a retro styled terminal in SM64coopdx, with over 8 different minigames and 5 shaders for you to choose from! Make Mario HUGE or TINY as a mouse , spawn whatever objects you want on the map with commands.
